### DEVI
Open-source Windows tools for examiners that work offline. Every download has a SHA-256 checksum on its tool page, and each lab should validate a tool under its own procedures before relying on it.

| Tool | What it does |
| --- | --- |
| **[DEVI Validate](https://deviops.app/tools/devi-validate/)** | Read-only evidence hash checker. Checks SHA-256, SHA-1, and MD5 against sum files, CSV, and FTK Imager logs, and writes a PDF verification record. |
| **[DEVI Decrypt](https://deviops.app/tools/devi-decrypt/)** | Decrypts Apple and iCloud OpenPGP provider returns, offline. |
| **[DEVI Registry](https://deviops.app/tools/devi-registry/)** | A sourced database of application and artifact metadata, with an offline app to look an app up. Every record cites its sources. |

A fourth tool, DEVI Sandbox, is in development. The source lives in the **[Deviops-app](https://github.com/Deviops-app)** organization, starting with DEVI Validate, with the other tools following.
