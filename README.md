### DEVI
Offline Windows tools for examiners, built by DEVI Ops LLC. Every result points back to its source, every download has a published SHA-256 on its tool page, and each lab should validate a tool under its own procedures before relying on it. Access is for approved accounts, and there's no cost to request it at [deviops.app](https://deviops.app).

| Tool | What it does |
| --- | --- |
| **[DEVI Validate](https://deviops.app/tools/devi-validate/)** | Read-only evidence hash checker. Checks SHA-256, SHA-1, and MD5 against sum files, CSV, and FTK Imager logs, and writes a PDF verification record. |
| **[DEVI Decrypt](https://deviops.app/tools/devi-decrypt/)** | Opens Apple and iCloud OpenPGP provider returns offline. Its record never holds the key. |
| **[DEVI Registry](https://deviops.app/tools/devi-registry/)** | A sourced database of app artifacts, parsers, and legal-process contacts, each marked Verified, Reported, or Disputed. |

DEVI Reader, an offline reader where every finding is cited to its source record, is in private testing.
